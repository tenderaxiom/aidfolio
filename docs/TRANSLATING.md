# Translating Aidfolio

Priority languages: Sinhala, Tamil, French, Arabic.

1. Every user-facing string sits in index.html: the AREAS object (questions, options, statements, documents) and the page text.
2. Translate meaning, not words. Keep sentences short. Use the term local organisations actually use for each document.
3. A second fluent speaker who works in a local organisation reviews every translation before release.
4. Do not translate the names of the UN assessments (HACT, PSEA); add a local gloss after them if useful.
5. Credit: translators are listed on the site with their permission.

When the project moves to Hosted Weblate, these strings will be extracted into one file per language.
