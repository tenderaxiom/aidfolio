# Toolbox: free resources

The list behind the Toolbox section and the "Free help" links on every gap. Source of truth: `RESOURCES` and `TOOLBOX` in `public/index.html`.

**Rules for adding a resource**

1. Free to use for local organisations (no paywall; free registration is acceptable).
2. Practical: it helps someone do the task, not only read about it.
3. Prefer resources available in several languages or written for small organisations.
4. At most four per task. If a better one appears, replace rather than add.
5. Record the month you checked it. Re-check every entry each quarter; the GitHub link check flags broken links on every commit.

Last full check: October 2026.
