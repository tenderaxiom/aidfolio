# Open evidence on local running costs: data protocol

**Purpose.** No public dataset compares local organisations' real running (shared) costs with the overheads their
grants allow. With consent, Aidfolio collects anonymous percentages to publish totals that support fairer overhead
policies.

**How data arrives.** Only by email that the organisation chooses to send from the Fair cost tool. The tool shows the
exact email text first. Nothing is sent automatically, and the website has no server that receives data.

**What the email contains:** year; true overhead rate; shared costs as a share of all spending; number of grants;
average overhead allowed by grants; share of shared costs unfunded; unrestricted income as a share of shared costs;
and, only if the sender chooses, a spending band, an organisation type and the country. No names, no amounts.

**Handling.**

1. Within 7 days of receipt, copy the figures into the dataset without the sender's email address, then delete the email.
2. Keep the dataset offline or in a private file. Record only: date received (month), the figures above.
3. Never reply to a sender with anything that links them to their figures in public.

**Publishing rules.**

- Publish only totals (median and range) for a group of 10 or more organisations.
- Publish a breakdown (by country, type or size band) only if each group has 10 or more organisations.
  Otherwise merge groups or leave the breakdown out.
- Publish aggregates under CC BY 4.0, with this protocol and the number of organisations behind each figure.
- State the limits: self-selected, self-reported, unaudited estimates; not a representative sample.

**If someone asks to withdraw.** Because emails are deleted after extraction, figures cannot be linked back to a sender.
Say so plainly in the published method.
